虚拟祈福网站

页面结构 / 信息架构 · v1

一、整体页面层级概览

首页 / 入口 ├── 殿堂选择页 │ ├── 平安殿 │ ├── 财神殿 │ ├── 姻缘殿 │ ├── 文昌殿（学业） │ └── 综合 / 其他殿堂 │ ├── 殿堂内页（核心场景页） │ ├── 主殿视觉区（大殿 + 主尊） │ ├── 香火区（正在燃烧的香） │ ├── 操作区（点香、添香、贡品等） │ └── 轻互动区（木鱼、念珠、功德箱） │ ├── 点香 / 祈愿流程页（弹窗或独立步骤页） ├── 添香确认页（弹窗） ├── 还愿页 ├── 个人祈福册（我的记录） ├── 香火 / 商品选择页 └── 辅助页面 ├── 关于本站 / 声明页 ├── 规则说明 └── 简单设置

二、核心页面详细说明

1. 首页 / 入口页

职责：建立第一印象，快速引导用户进入祈福流程。

  • 品牌/站名 + 一句简洁的定位文案
  • 大型主视觉（宏伟大殿或主尊局部，强调庄严感）
  • 主要行动按钮：「开始祈福」或「进入殿堂」
  • 次要入口：我的祈福册、关于本站
  • 底部简短声明（虚拟体验、非正式宗教）
设计重点：第一眼要有震撼感和安静感，避免信息过载。

2. 殿堂选择页

职责：让用户根据祈求类型选择对应殿堂。

  • 殿堂卡片列表（平安殿、财神殿、姻缘殿、文昌殿等）
  • 每个卡片包含：殿堂名称、简短描述、氛围图/图标
  • 可显示当前在线人数或“香火旺盛”程度（可选）

3. 殿堂内页（最核心页面）

职责：用户停留时间最长的页面，承载主要体验。

区域 内容 说明
上方 / 主视觉区 大殿全景 + 巨大主尊 强调宏伟与庄严，主尊要大
中部香火区 正在燃烧的香（自己的 + 他人的） 显示剩余时间、已被添香次数
操作区 点香、添香、供奉贡品、买符等按钮 清晰分层：免费操作 vs 付费操作
轻互动区 木鱼、念珠、功德箱 可随时点击，增加仪式感

4. 点香 / 祈愿流程

建议形式：步骤式弹窗或独立流程页。

  1. 选择香的类型（普通免费 / 高级付费）
  2. 确认位置（普通位置 / 更中间位置）
  3. 写下祈愿文字（可匿名，有字数限制）
  4. 确认并点燃
  5. 点燃成功反馈（动画 + 提示）

5. 添香流程（弹窗）

  • 显示原香的简略信息（剩余时间、已被添次数）
  • 选择添香类型（不同金额/效果）
  • 确认支付
  • 成功后的反馈动画
流程要极短，降低决策成本。

6. 还愿页

  • 选择要还愿的祈愿记录
  • 还愿方式选择（基础免费 / 进阶付费）
  • 可添加感谢语（匿名感谢曾经添香的人）
  • 还愿成功动画与确认
设计重点：仪式感要强，让用户有“正式完成”的感觉。

7. 个人祈福册（我的记录）

  • 进行中的祈愿（正在燃烧的香）
  • 历史祈愿记录
  • 已还愿记录
  • 我购买的符咒 / 贡品
  • 被添香次数统计

8. 辅助页面

  • 关于本站 / 声明页：明确虚拟体验定位、非正式宗教、免责声明
  • 规则说明：简单说明点香、添香、还愿规则
  • 设置：音效开关、是否默认接受他人添香等

三、页面优先级建议

P0 必须先有：首页、殿堂选择页、殿堂内页、点香流程、基础还愿、个人祈福册（基础版）

P1 重要增值：添香功能、高级香与位置、贡品、进阶还愿

P2 体验增强：符咒、功德箱、高级木鱼/念珠、更完整的个人记录

四、信息架构原则

  1. 减少层级：核心操作尽量在殿堂内页完成，少跳转。
  2. 付费点清晰但不打断：付费选项存在，但不阻挡免费流程。
  3. 状态可见：香的燃烧时间、添香次数要始终容易看到。
  4. 庄严感优先：页面信息不能太满，留出呼吸感，突出主殿视觉。
  5. 移动端优先：考虑到年轻人主要使用手机。

虚拟祈福网站 · 关键用户流程图

v2对齐 PRD V1.0 第七章更新于 2026-11-14
V1.0 只有三条路径：为自己祈愿、保住/找回记录、为他人送祝福。全程无支付环节，无殿堂选择，香火固定 30 分钟。

一、总览流程

【进入】Home ↓ Enter the Temple 【Temple 主殿】香炉 · 香火 · 柔和光 │ ├─→ Light Incense / Make a Wish │ ↓ │ 填写愿望（≤200 字，无需姓名、无需邮箱） │ ↓ │ 确认祈愿 → 创建 Wish + Incense（服务端时间） │ ↓ │ Incense 页：30:00 倒计时（ends_at − now） │ ↓ │ 用户关闭页面 —— 香火按 ends_at 继续，不依赖浏览器 │ ├─→ Send Kindness │ ↓ │ 选对象（5 类）→ 选预设祝福语 → Send Blessing → 成功反馈 │ └─→ My Wishes ↓ 愿望列表（愿望 / 点香时间 / 香火状态 / 还愿状态） ├─→ Protect My Wishes → 邮箱验证 → 绑定成功 └─→ Fulfill a Wish → 标记实现 + 可选感言 【回访】再次进入 → My Wishes → 剩余时间由 ends_at 实时计算 【到期】ends_at ≤ now → 香火 Burning → Completed（自动，无需用户操作） 【找回】换设备 / 清缓存 → 用已验证邮箱登录 → 原记录全部回来

二、三条主流程

流程 1 · 个人祈愿（主路径）

  1. 打开 Home → 点击 Enter the Temple
  2. 进入主殿，看到香炉与正在燃烧的香火
  3. 点击 Light Incense，进入 Make a Wish
  4. 输入愿望（默认私密，不要求姓名与邮箱）
  5. 确认祈愿 → 系统创建愿望记录 + 香火记录
  6. 跳转 Incense 页，显示 30:00 倒计时与状态 Burning
  7. 用户离开网站，香火继续燃烧
  8. 再次访问 → My Wishes 查看状态
  9. 愿望实现后 → Fulfill a Wish 完成还愿

流程 2 · 保存与找回记录（可选）

  1. 进入 My Wishes
  2. 点击 Protect My Wishes
  3. 输入邮箱 → 系统发送带有效期的验证链接
  4. 点击邮件链接完成验证
  5. 邮箱与原有匿名身份关联，已有愿望全部保留
  6. 换设备后通过邮箱验证找回记录
必须提示的风险：未绑定邮箱的匿名用户，清除浏览器数据或更换设备后可能无法找回记录。此提示需在 My Wishes 与绑定入口处清楚但不吓人地说明。

流程 3 · 免费送祝福

  1. 点击 Send Kindness
  2. 选择对象：Family / Friends / Someone in Need / A Stranger / Everyone
  3. 选择一条预设祝福语（不可自由输入）
  4. 点击 Send Blessing
  5. 显示成功反馈，无需注册、付费或对方回应

三、香火时间机制（30 分钟）

项目规则
点燃记录 started_at，同时算出 ends_at = started_at + 30min
倒计时每次加载都按 ends_at − 服务器当前时间 计算，浏览器只负责显示
关闭页面不影响计算；再次访问时剩余时间自动正确
跨设备同一身份下结果一致（取决于后端时间，不看本地时钟）
状态流转Burning → Completed，到期自动更新，不可回退
V1.0 不做不做香等级、不做付费延长、不做他人添香、不做多柱同时燃烧

四、异常与边界

情况处理方式
匿名凭据丢失无法自动恢复；引导用已验证邮箱找回，或重新开始
邮箱验证链接过期允许重新发送，令牌带有效期，旧令牌作废
愿望超长 / 空白前端限制长度并提示，后端二次校验；空内容不允许提交
重复点击点燃按钮提交后置灰，服务端幂等，避免生成两条香火记录
网络中断状态以服务端为准，重新进入即恢复到正确剩余时间
内容违规V1.0 愿望私密、不公开；后续开放公开内容前需先建审核机制（PRD 第十二章）

五、与 v1 的差异

v1 中的设计v2 / PRD V1.0 的处理
殿堂选择页平安殿 / 财神殿 / 姻缘殿 / 文昌殿删除。V1.0 只有单一主殿，多殿堂列入 V1.5+
高级香（付费）更长燃烧、更好位置删除。只有一种 30 分钟香，不做等级与付费延长
添香支付他人付费延长你的香移出 V1.0，属 V2.0「为陌生人添香」
贡品 / 符咒 / 功德箱 / 木鱼念珠移出 V1.0；木鱼念珠列入 V1.5 体验增强
进阶还愿（付费）删除。还愿只有一种，免费，可写可选感言
香火「剩余 3 小时」等长时长统一为 30 分钟，由服务端计算
邮箱绑定v1 未提及新增 P0：可选绑定，用于跨设备找回记录
30 分钟香火v1 未提及新增 P0：唯一香火时长与状态机

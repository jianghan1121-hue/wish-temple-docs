一、总览流程图

【启动】 用户打开网站 ↓ 【首页】看到主视觉 + 「开始祈福」 ↓ 【殿堂选择页】选择祈求类型（平安/财运/姻缘/学业...） ↓ 【殿堂内页】进入对应大殿（看到巨大主尊 + 正在燃烧的香） ↓ ├──→ 直接观看 / 敲木鱼 / 拨念珠（免费轻互动） │ ├──→ 【点香流程】 │ ↓ │ 选择香的类型 │ ├── 普通香（免费） │ └── 高级香（付费） │ ↓ │ 写下祈愿文字（可匿名） │ ↓ │ 确认点燃 → 返回殿堂内页 │ ├──→ 【添香流程】（看到别人的香） │ ↓ │ 点击某柱香 → 选择添香 → 支付 │ ↓ │ 添香成功（时间延长或光效增强） │ ├──→ 购买贡品 / 符咒 / 投功德箱（可选付费） │ └──→ 离开（香继续在后台燃烧） 【回访路径】 用户再次进入 ↓ 查看自己香的剩余时间、被添香次数 ↓ ├── 香还在燃烧 → 继续等待 / 升级 └── 香已燃尽 / 愿望已实现 → 进入【还愿流程】 【还愿流程】 选择要还愿的记录 ↓ 选择还愿方式（基础免费 / 进阶付费） ↓ 可匿名感谢曾经添香的人 ↓ 还愿成功 → 记录进入「已还愿」

二、分场景详细流程

场景1：首次祈福（主路径）

  1. 打开网站 → 首页
  2. 点击「开始祈福」
  3. 进入殿堂选择页 → 选择例如「文昌殿」
  4. 进入殿堂内页，看到庄严主尊和已有香火
  5. 点击「点香」
  6. 选择香：普通香（免费）或高级香（付费）
  7. 输入祈愿内容，可勾选匿名
  8. 确认点燃，播放点燃动画
  9. 回到殿堂内页，自己的香出现并显示剩余时间
  10. 可继续供奉贡品、敲木鱼，或离开

场景2：为他人添香（助力路径）

  1. 在殿堂内页浏览正在燃烧的香
  2. 看到某柱香显示“剩余3小时 | 已被添香2次”
  3. 点击该香 → 弹出添香选项
  4. 选择添香规格并确认支付
  5. 播放添香动画，原香状态更新

场景3：回访查看进度

  1. 再次打开网站
  2. 从「我的祈福册」或直接进入对应殿堂
  3. 查看自己进行中的香：剩余时间、被添香次数
  4. 可选择继续等待、再次添香或购买贡品
  5. 如果香已燃尽且愿望实现，出现「去还愿」引导

场景4：还愿闭环

  1. 进入还愿页或从祈福册点击「还愿」
  2. 选择对应的祈愿记录
  3. 选择还愿规格（基础免费 / 进阶付费）
  4. 可选：勾选“感谢曾经为我添香的人”
  5. 确认还愿，播放庄重动画
  6. 还愿成功，记录移至「已还愿」

三、免费 vs 付费路径对比

行为 免费路径 付费增值路径
点香 普通香，短时间，普通位置 高级香，长时间，更好位置，更美特效
助力他人 不可行 可添香，延长时间或增强效果
供奉 无 可买虚拟贡品摆上供桌
符咒 无 可购买并收藏
还愿 基础还愿 进阶还愿（更隆重）
互动 基础木鱼、念珠 高级特效版本
原则：免费路径完整可走通，付费只提升体验与情绪价值。

四、关键决策点与引导建议

  1. 点香时：明确对比普通香 vs 高级香的差异，但默认选中免费选项。
  2. 添香时：流程尽量短（2-3步完成），降低冲动支付的阻力。
  3. 香快燃尽时：可在个人祈福册给予轻提示。
  4. 愿望实现后：在祈福册显著位置引导“去还愿”。
  5. 空状态：殿堂刚进入、还没有香时，要有友好的引导文案。

五、流程设计原则总结

  1. 主路径越短越好，让用户快速完成第一次点香。
  2. 付费点出现在“已经产生情绪”之后（看过香、写完祈愿）。
  3. 回访路径要清晰，香的状态始终可查。
  4. 还愿是高光时刻，仪式感要足够强。
  5. 全程保持零社交压力，不出现聊天、评论、强制分享。

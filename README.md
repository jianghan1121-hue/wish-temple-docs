## 二、PRD V1.0 速览

### 已确定（13 项）

| 事项 | 决定 |
|---|---|
| 产品定位 | 全球愿望与祝福空间，A Place for Wishes and Kindness |
| 文化特色 | 中国传统文化视觉根基，不要求宗教信仰 |
| 目标市场 | 海外市场，英文优先 |
| 基础功能 | 永久免费（点香、祈愿、记录、还愿、送祝福） |
| 第一阶段殿堂 | 一个主殿（不做多殿堂） |
| 用户身份 | 默认匿名，可选邮箱绑定 |
| 记录恢复 | 通过已验证邮箱找回 |
| 香火时长 | 30 分钟，服务器时间计算 |
| 免费祝福 | 仅预设祝福语，不开放自由输入 |
| 自定义祝福 | 暂缓 |
| 复杂 3D | 暂缓 |
| 多殿堂 | 暂缓 |
| 商业伦理 | 不利用恐惧和焦虑赚钱 |

### 仍需确定（9 项）

1. 正式英文名称和域名
2. 主殿最终视觉设计
3. 前端技术
4. 后端技术
5. 数据库服务
6. 海外部署服务
7. 邮箱验证服务
8. 备份与恢复机制
9. 上线前法律合规审查
